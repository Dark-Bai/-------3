# 盘口·K线·量价·分时

> 把"买在最低、卖在最高"变成可执行：支撑压力定价位、盘口衰竭定瞬间、量价背离定方向、分时乖离与做T仓位定节奏。

## 核心框架（做T五要素）
- 市场环境（大局观先行：环境决定水下是机会还是风险）→支撑压力（大量点/爆量点=支撑；爆量高点=压力）→盘口（攻击力度/持续性/衰竭点，精确到秒）→分时量价（顶背离卖/底背离买）→仓位（等仓或至少半仓，否则做T无意义）。
- 卖在最高公式：压力位+分时背离+盘口衰竭→主动卖，不等百万级砸盘先砸；反之空方衰竭+支撑位+背离→先抄底。
- 检查顺序：环境定方向→支撑压力定价位→盘口定时机→分时量价定确认→仓位定规模。

## 盘口
- 多方攻击盘口：100万级大单连续吃卖盘、价格逐档上扫；看连续性（很多大单在盘口外"空中成交"，单看一帧无意义）。空方反之。
- 盘口衰竭（核心卖点）：多头连续攻击攻击不动+空头出手=衰竭点（10.74被砸778万+10.66挂526万压单）。空头衰竭（买点）：千万级单子连续吃货（吃光406万+109万还余6638万）。
- 整数关口衰竭：关键整数位抛压大（11块挂624万），日内已涨高（8.51%）若不能快速吃掉并封板→衰竭点。
- 封板盘口：早盘缩量上板预期1-3亿大单堵门；3秒应反应、6秒没人堵门（封单仅4400万还被砸）=不及预期、封不住走成尖角波→板上砸。

## 竞价盘口
- 竞价三图排序（竞价涨幅/金额/主力金额）：筛出竞价表态的强势票；主力金额只能竞价阶段看（开盘即变）；看撤单（9:20前撤单太多=假封）与抢筹方向（9:20后看加单堵门还是借高开出货）。
- 竞价表态+开盘拉伸+环境好（指数强/题材有方向/情绪好）才容易冲板；环境弱势竞价表态也可能走不出来。
- 竞价买点：两市竞价三一（金额/换手靠前）+次高板+开在1%附近+开盘拉伸表态→"竞价干一笔、开盘拉伸干一笔"2B买入法。

## K线与量价
- 单K：底部涨停K线=资金信号（次日爆量确认，底部爆量多数是吃货）；爆量分时大震荡=顶部信号线（次日无量急拉=最后逃命点）。
- 多K组合：缩量涨停→爆量→爆量后高开转一致=标准买点（循环可重复，买点越靠后风险越高）；缩量反包（环境+地位+第一买点支持可参与）；缩量再缩量加速=完全无买点只出不进；缩量回踩关键支撑不破=确定性较高入场。
- 爆量底层逻辑：充分筹码交换+主力成本重置（爆量线=新资金成本）。爆量当日不买（无法确认吃货还是出货，个别龙头除外）；次日高开转一致=买点、低开=只卖不买。
- 缩量上涨本质：筹码稳定（好）但浮筹脱离主力成本区（易被砸）；缩量不接（缩量加速票开板环境弱就爆量）。缩量可买四件套：龙头地位+第一/第二买点+模式保证+上升期环境。
- 量价背离（分时级）：顶背离=第一波大量、第二波无量创新高（"油不够了"）=卖点；底背离=越跌量越大=关键价位有承接=买点（90%买卖在极值附近）。
- 分工：分时背离解决日内买卖"点"（配合盘口衰竭精确到秒）；日K爆量/缩量解决次日预期与上车（方向）。不可混用。
- 支撑压力三法：多日分时（下探不破=低吸、突破前高=突破买点、上板炸板=减仓）；5分K（涨停板=强支撑、多次穿越不过=压力、爆量点最高点=压力）；日K突破（站稳=买点、炸板回踩不破=低吸点）。
- 颈线纪律：一破颈线成空方（生命线）。止损顺序：破第一颈线（支撑平台）出局→第二颈线（多次回踩不破）再破再减→强支撑全破清仓。

## 分时技巧（做T）
- 做T方向：DC低吸（水下买入博修复，条件见速查表）；震T（日内高抛低吸）；倒T（先卖后买）。
- 做T五步：定环境（上升期→水下缩量核心票低吸；退潮期→水下是风险，开盘就卖）→画支撑压力→盯盘口（攻击启动/空方衰竭）→看分时量价（顶背离减/底背离吸）→管仓位（等仓或半仓）。
- 减仓做利润垫=永不亏钱：利润垫做实后深水才敢抄底做T；减仓是最科学的心态保险。
- 卖点六信号：①非绝对龙头涨停/炸板必减（弱势防未发生风险）②分时背离减（第一次几率性减仓、第二次必减）③分时乖离减（大容量5个点+、主板7/8/9、创业板15+）④离别沟（早盘爆量走弱后午后无量急拉=逃命点95%，拉上去先减）⑤789减仓（主板7/8/9减，不赌涨停；创业板15+减）⑥压力位减（日K爆量高点/前高平台/周K历史前高过不去减；跳空破压力=一破颈线=最后卖点必出局）。
- 缩量板减仓：早盘缩量冲板+无大单堵门=预期内炸板→板上减（或炸板时减），别等杀下来割。
- 卖点主次：地位（非绝对龙头涨停/炸板必减）>位置（压力/颈线）>概率（背离/乖离/789）>逃命（离别沟）。盘中：位置→量价→盘口；三重共振=卖在最高；支撑+底背离+空方衰竭=买在最低。
- 分时基本功：均线上去=日内成本抬高、抛压减轻；尖角波=无资金主封/情绪退潮；分时+量柱+盘口三者同步看。

## 关键量化速查
| 场景 | 条件 |
|---|---|
| 多方攻击 | 100万+大单连续吃卖盘 |
| 缩量板封板 | 1-3亿堵门；3秒反应、6秒没堵=不及预期 |
| 盘口衰竭卖点 | 攻击不动+空头出手 |
| 空头衰竭买点 | 千万级单子连续吃货 |
| 做T仓位 | 等仓或至少半仓 |
| 分时乖离 | 大容量5+、主板7/8/9、创业板15+ |
| 爆量处理 | 当日不买；次日高开=买点、低开=只卖不买 |
| 离别沟 | 午后无量急拉=逃命点95% |
| 水下低吸DC | 上升期+水下缩量+支撑不破+金额流入 |

## 纪律
- 做T看环境：同样的水下缩量，上升期是机会、退潮期是风险；脱离环境谈分时=刻舟求剑。
- 缩量票无脑低吸=接爆量出货；只有"龙头+第一/第二买点+模式+环境"四件套才可缩量买。
- 爆量当天追买=错（分歧无法确认吃货还是出货）。
- 分时背离舍不得减→割在最低点、心态爆炸；幻想离别沟是地天板=错。
- 非绝对龙头涨停不减仓="不按纪律来就挨揍"（天地板=10万亏2万）。
- 只做T不管仓位=无意义；破颈线赌修复=错。
- 只看信号不凭主观：主观幻想都会被市场砸。
- 保护心态第一原则：宁可少赚两个点，不让利润回吐。
