# 财报窗口（/fin）UI 重设计稿

基准：`docs/design-ref-main.png`（主页 = 品味基准） vs `docs/design-ref-fin-current.png`（现状）。数据源与组件结构不变：6 面板各一组件 + `Panel` 容器，本稿只重排行结构与面板内部。

## 一、主页品味 DNA（基准归纳）

**信息密度与节奏**
- 列表行高 17–20px（IndexPanel 行 `py-[1.5px]` + 12px 主数字 ≈ 19px）；每面板 8–12 行，行内 4–6 个信息点（名称/主数/涨跌 chip/分时/副数）。
- 列表与图表不分区：分时 Spark（120×16）直接嵌在行内，图表是列表的一列；独立图表面板也用 8.5px 端点标签堆数据。
- 密度基准：指数面板 ≈ 12 行 × 5 点 = 60+ 信息条；热点面板 6 行 × 4 点 + 侧栏明细。fin 各面板以此为下限。

**色彩纪律**
- 底色三层：页底 `#070b12`、面板 `#0c1320/90`、hover/卡 `slate-800/30–40`；描边 `slate-700/40`。
- 强调色（cyan/sky `#38bdf8`）面积 <2%：只用于标题色条（1×14px）、选中 Tab、图标 glyph。
- 红涨绿跌只落在数字与 ≤56px 宽的涨跌 chip 底上；全屏无一处大面积纯色块。

**数字排版**
- 一律 `tabular-nums`、右对齐；主数 12px bold、涨跌 10px semibold 带圆角底色（`bgChg`）、辅助 9px slate-500、刻度 8px。
- 颜色 = 涨跌，粗细 = 主从；正 rose `#fb7185` / 负 emerald `#34d399` / 无数据 slate-600 横杠。

**图表语言（手绘 SVG，Spark/BoardFlowChart 范式）**
- 线宽 1.2–1.4px 圆角 join；面积填充 opacity 0.12；网格 `#1e293b`、零轴 `#334155`（或 `#475569` dashed 2,3）；刻度 8–9px `#475569/#64748b`。
- 无图例框：端点标签 + 红绿约定代替图例。

**terminal 感来源**
- Panel 头 h-8：accent 色条 + 13px semibold 标题 + 右侧 10px slate-500 meta（刷新间隔/合计）+ 22px 线框 zoom 钮。
- 微标签：8px `bg-slate-700/50` rounded-sm chip（地区码）、8.5px 边框 chip（概念/类型）；分割靠 1px `border-slate-800/60` 行线，不套卡片。

## 二、现状诊断（为什么不行）

1. **财报日历**：14 天柱带被拉成左 38% 宽的纵向大图，实际只有 1 根柱 → 90% 死空间；右栏清单 3 行悬顶，面板 28% 高度只装 5 条信息（主页同面积 25+）。
2. **业绩预告**：行内容两端拉扯——日期+名称+chip 靠左、净利区间靠最右，中间 40% 全空，每行视线横跨 ~600px；行高约 46px（主页 19px）；顶部统计条独占 22px 又与明细列重复表达同一批数据。
3. **行业盈利榜树状图**：头部「电池 438亿」一块纯色占面板 1/4，大面积 rose 平涂与全站"细线条 + 12% 面积填充"语言割裂；无网格无刻度无排序轴，15 个行业吃掉半个屏，密度 ≈ 主页 1/4。
4. **公司财报**：6 张指标卡每张 ~70px 高、gap 12px，2×3 网格撑满面板只有 6 条信息。
5. **整体**：行高/卡高/间距全面是主页的 1.5–2 倍，三行均分是"网页排版"而非"终端密度分区"。

## 三、设计 token（px 值，对齐主页实测）

- 行高：紧凑表 18px（日历清单/预告明细）、榜单 20px（个股榜）；行业条形 16px；行 padding-x 4–6px。
- 字号：面板标题 13 semibold；区段小标 9px uppercase tracking-widest slate-500；名称 11px slate-200；主数字 12px bold tabular-nums；涨跌/同比 10px semibold 红绿；辅助/刻度 8–9px slate-500；chip 8.5px。
- 间距：面板体 `p-1`（4px）；卡/chip gap 4–6px；行分隔 `border-b border-slate-800/60`；hover `bg-slate-800/40`。
- 色：页底 `#070b12`；面板 `#0c1320/90` + `border-slate-700/40`；网格 `#1e293b`、零轴 `#334155`、刻度 `#475569/#64748b`；正 rose `#fb7185`、负 emerald `#34d399`（底色一律 12% 透明度）、今日/重磅 amber `#fbbf24`、选中 cyan `#22d3ee`。
- 图表：SVG 线宽 1.2–1.4、面积 fill ≤0.12、ResizeObserver 实测宽高；任何色块 fill opacity ≤0.25 + 1px 同色 40% 描边——**禁止 100% 不透明平涂**。

## 四、行结构

Row1 26%：finCalendar 38% + finForecast 62%；Row2 40%：finIndustry 50% + finStockRank 50%；Row3 34%：finCompany 30% + finTrend 70%。面板数不变，宽度向信息多者倾斜。

## 五、逐面板设计

### finCalendar 财报日历 — 柱带压顶 + 双列清单（密度 ≥30 条）
```
┌ ▌财报日历 ─────────────── 今日 0 家 · 峰值 3 家(08/03) ─ ⊙ ┐
│ ▁▁▁▁▁▁▁▁▁▁▁▁▁█  14 天柱带 h=40px: 今日 amber 实色+柱顶 8px 数字│
│ 今天      +3       +7      +14   未来 cyan/40 过去 slate-700 │
│ 今晚披露 08/03(amber 9px 小标) │ 明日 08/04                  │
│ 一博科技   26Q2  ★           │  —                          │
│ 华之杰     26Q2              │ 近 3 日 08/05–08/07          │
│ 朝阳科技   26Q2              │  …                          │
└──────────────────────────────┴──────────────────────────────┘
```
- 柱带从"左栏大图"降为全宽 40px 横带 + 8px 刻度行（今天/+3/+7/+14）；右下清单双列流式，行高 18px：名称 11px slate-200、期 9px slate-500、重磅 ★ amber。
- 统计句 `今日 N 家 · 峰值 M 家` 从面板底部移入标题栏 right 槽（10px slate-500，N amber），不再占体高。

### finForecast 业绩预告 — 统计入标题栏 + 固定列紧凑表（密度 ≥25 条）
```
┌ ▌业绩预告 ─ 预喜 49▲ 预悲 9▼ 未定 2 ───────────── ⊙ ┐
│ ██████████████████░░  3px 堆叠条贴标题栏下(rose/emerald/slate)│
│ 08-01 *ST京化  [扭亏]  4,000万~4,800万  +145.0%~+154.0%     │
│ 07-31 天微电子 [预减]  163万~163万      −94.1%              │
│ 07-31 大烨智能 [扭亏]  600万~900万      +113.9%~+120.8%     │
│ …行高 18px, 列宽固定: 40 | flex | 34 | 140 | 120           │
└─────────────────────────────────────────────────────────────┘
```
- 统计条从 22px 独立区压缩为 3px 贴头条；`预喜/预悲/未定` 数字移入标题栏 right 槽（10px 红绿 tabular-nums）——消除与明细的重复表达。
- 明细列固定：日期 9px slate-500(w40)｜名称 11px｜类型 chip 8.5px(w34)｜净利区间 11px tabular 右对齐(w140)｜同比区间 10px 红绿右对齐(w120)。数字列相邻，视线动线不再横跨面板。
- chip：预增/略增/扭亏/减亏=rose 系、预减/略减/首亏/增亏=emerald 系、未定=slate；首亏加 amber 左点。同比区间上下限同号时只染一次色。

### finIndustry 行业盈利榜 — 树状图 → 条形矩阵（密度 ≥45 条）
```
┌ ▌行业盈利榜 ─ 26Q2·披露中|26Q1·全市场 ‖ 条形|树状 ─ ⊙ ┐
│ 电池      ████████████████ 438亿 +142.5%                │
│ 工业金属  ██████ 108亿 +115.1%                          │
│ 专用设备  ███ 38亿 +867.8%                              │
│ …TOP15, 行高 16px: 名称 9px w64 | 条(对数压缩) | 右端双值  │
│ └ 0        200亿        400亿   8px 金额刻度 3 档        │
└─────────────────────────────────────────────────────────┘
```
- **论证**：15 项小样本下面积编码被头部（438亿 vs 中位 ~20亿）挤压，后 10 名缩成无法阅读的碎片；排序条形让"规模（条长）+ 景气（条色）"双读且天然有序，与 Spark/BoardFlow 细线语言一致。故**默认视图改为条形矩阵**。
- 条形：SVG，条长 ∝ 净利对数压缩（防头部吃轴），条色按同比 rose/emerald fill 25% + 1px 同色 60% 描边；右端 8.5px 双值（金额 slate-300、同比随条色）；负同比行条 40% 透明 + 虚线描边。
- 树状 Tab 保留但**线框化**：色块改为 fill 12% + 1px 同色 40% 描边，文字 slate-200/slate-400，消除色块墙。
- 刻度行 8px `#64748b` 3 档自动取整，贴底部 16px 高。

### finStockRank 个股盈利榜 — 保结构、提密度（TOP20 全显）
```
┌ ▌个股盈利榜 ─ 26Q2·披露中 ‖ 净利额|增速 ─ ⊙ ┐
│ 1 宁德时代  ▓▓▓▓▓▓▓▓ 433亿  +42.0%  ROE 12.1%│
│ 2 海康威视  ▓▓ 79亿  +39.6%  ROE 9.2%        │
│ …行高 20px; 底条=占第一名比例 rose 4% 透明度铺行底│
└──────────────────────────────────────────────┘
```
- 行高 22→20px；名次 9px slate-500（前三 amber/rose/cyan）；净利 12px semibold、同比 10px 红绿、ROE 9px slate-500 右对齐定宽列；行底相对值横条（4% rose/emerald，∝ 占第一名比例）。
- 增速 Tab：主列换净利同比加粗，底条 ∝ 增速；亏损企业置底 9px 注 `扭亏/亏损`。

### finCompany 公司财报 — 卡片收紧为 3×2（密度 6→14 条）
```
┌ ▌公司财报 ────────────────── 贵州茅台 ─ ⊙ ┐
│ [输入代码/名称_______________]  24px       │
│ [茅台][宁德][海康][东财] 最近查看 chips 18px│
```

- 卡高 70→40px：标签 9px slate-500、值 13px semibold tabular-nums、同比 9px 红绿同行右侧；搜索框 30→24px；最近查看 chips 单行 18px。
- 与个股榜联动：点击榜单行载入公司（已有交互则保留）。

### finTrend 公司趋势 — 微调即可
- 双轴组合图保留；柱组宽 ≤60%、组内 gap 2px；X 刻度每 2 期 8px；折线末端补 8.5px 端点标签（复用 BoardFlowChart 均布算法）；`业绩|质量` Tab 移标题栏 right 槽不变。

## 六、状态与适配

- 加载：骨架行（`bg-slate-800/40` h-3 rounded，按目标行数渲染）+ 11px slate-600 `数据加载中…`；失败：整面板 `<button>` `数据获取失败，点击重试` slate-500。
- 空态：日历柱带照常渲染（0 值柱）+ `未来 14 天暂无披露安排`；预告隐藏贴头条与统计 meta，`当前非业绩预告密集披露期`；公司未选：指标区 `← 从榜单或搜索选入公司`、趋势区灰化骨架。统一 11px slate-600 居中。
- TV（CSS zoom ≤3，Panel 统一处理）：行高固定 px 禁止内容自适应；所有 Tab/chip/重试必须 `<button>` 且热区 ≥22×22px（标题栏 Tab `h-[22px] px-2` 10px）；zoom 后列表不增行、SVG 不重采样（RO 不触发，≤3x 位图化可接受）；行级不做焦点，焦点停在面板/按钮级（`data-tv-focusable`）。
