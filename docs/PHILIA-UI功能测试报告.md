## 3. 回归问题记录

- **修复前**：B 组点击配置入口触发 `openModal is not defined` 渲染崩溃（根因：PhiliaModal 移除解构后 `useEffect` 残留引用）。
- **修复后**：B 组全部通过，控制台无报错。
- 控制台存在若干非关键 API 请求中断（`net::ERR_ABORTED`，为组件切换时中止的 fetch），属正常行为，不影响功能。
