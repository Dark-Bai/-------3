## 一·补、数据采集完整性要求（每条网页必做）

采集任何网页数据前，必须执行以下关键动作，确保页面所有内容（含动态加载/隐藏内容）都被**完整呈现与捕获**，防止信息遗漏：

1. **完整上下滚动**：对页面执行完整的滚轮上、下滚动操作，直至页面到底且不再出现新内容，确保所有可见及滚动加载的内容均被捕获。
2. **左右滚动**：若页面存在横向滚动条（如宽表格、多列排行），执行左右滚动操作，确保不遗漏任何横向分布的信息。
3. **开发者模式（DevTools）结构检查**：打开浏览器开发者工具，从三方面核验页面结构：
   - **Elements 面板**：审查 DOM 结构，确认是否存在折叠/隐藏/DOM 中已存在但未渲染的内容，以及动态加载元素是否完整。
   - **Network 面板**：监控网络请求，确认表格/排行等关键资源均已成功加载（无 4xx/5xx、无超时），必要时刷新页面重新拉取。
   - **Console 面板**：检查是否存在 JavaScript 错误或警告；若存在，判断是否影响数据渲染，并在输出中如实备注。

> 上述检查做完、确认数据完整后，方可进入「二、分析维度」进行研判。

## 一·补3、昨日连板梯队复盘与今日实盘对照验证

> 本节为**标准化双日对照流程**：先系统复盘「昨日连板梯队」及其个股在「今日实盘」中的实际表现，再与「今日最新连板梯队」逐项对照，从而**验证昨日复盘结论（龙头核心、情绪周期、机会、风险）在今日市场中的应对状况、准确性及有效性**。
>
> **执行时序（重要）**：本节依赖「昨日数据」与「今日数据」两类输入。请在**完成「一、数据来源」对 6 个网页的当日数据读取之后、进入「三、输出格式」之前**执行本节流程：第 1–2 步消费昨日数据（通过日期切换），第 3–4 步消费今日数据（直接复用已读取的当日 6 页数据），第 5 步综合两日结果输出验证结论。本节产出的「双日对照验证」结果将作为「三、输出格式」的第 5 个固定模块输出。

### 流程总览（5 步，依次执行）

- **第 1 步 · 拉取昨日连板梯队**：按「一、数据来源」的历史数据获取方式，将网页 #2 / #6 日期切换至上一交易日，完整读取昨日收盘的涨停板明细与连板梯队。
- **第 2 步 · 建立昨日梯队名单**：按连板高度从高到低，结构化记录昨日梯队每只个股。
- **第 3 步 · 追踪今日实盘表现**：对昨日梯队逐一核对个股在今日交易中的实际走势。
- **第 4 步 · 与今日最新梯队对照**：将昨日梯队与今日最新连板梯队逐项交叉比对。
- **第 5 步 · 验证并输出结论**：将昨日分析结论与今日实盘结果对照，给出命中/偏差/失准评估。

### 第 1 步 · 拉取昨日连板梯队

1. **确认上一交易日**：以今天为基准向前回溯，跳过周末（周六/周日）与法定节假日；**判定是否交易日**的可操作标准——目标日期若为 A 股正常交易时段（周一至周五且非法定节假日）即为交易日；若遇法定节假日（如国庆、春节等），继续向前回溯至最近一个非节假日工作日。若对某日是否交易日存疑，可用「当日涨停家数是否 > 0」或「行情软件是否显示当日 K 线」交叉验证。
2. 在网页 #2（涨停板明细）与 #6（连板梯队）上通过日期选择器切换至上一交易日，等待页面刷新完成后读取。
3. 记录昨日关键指标：**涨停总家数、连板家数、最高连板高度、各连板高度对应的个股名单**。
4. 所有数据标注 `（来源：同花顺 涨停板明细 / 连板梯队 · 日期 YYYY-MM-DD）`。

### 第 2 步 · 建立昨日梯队名单

按连板高度**从高到低**建立昨日梯队结构化清单，逐只记录：

| 字段 | 说明 |
|------|------|
| 代码 / 名称 | 个股唯一标识 |
| 连板高度 | 昨日收盘时的连板数 |
| 所属板块 / 题材 | 判断梯队内部主线归属 |
| 昨日角色 | 总龙头 / 分支龙头 / 普通连板 / 首板 |
| 昨日封单/换手 | 判断分歧或一致 |

> 明确标出昨日判定的**总龙头与各分支龙头**，为第 5 步验证预留锚点。

### 第 3 步 · 追踪今日实盘表现

对第 2 步名单中的**每一只个股**，在今日盘中/收盘数据中核对其实际表现，逐只记录：

1. **竞价表现**：高开 / 平开 / 低开及其幅度（相对昨日收盘）。
2. **盘中走势**：盘中最/低、是否触及涨停、是否炸板及回封。
3. **收盘结果**：涨停（晋级）/ 上涨 / 平盘 / 下跌 / 跌停 / 停牌。
4. **晋级判定**：连板数是否较昨日增加（晋级）、维持（一字/换手板）、断板（未涨停）、反包（昨日断板今日涨停）或见顶（高位放量滞涨/大阴线/跌停）。
5. **量能变化**：成交、换手较昨日是否显著放大/萎缩。

> 数据来源（明确分工）：
> - **今日仍涨停/连板的个股**：今日涨停板明细（网页 #2）与最强个股透视（网页 #5）可直接覆盖，标注 `（来源：同花顺 涨停板明细 / 最强个股透视）`。
> - **昨日梯队中今日未涨停（断板/下跌/跌停）的个股**：上述聚合页**无法覆盖**，须逐只打开**个股行情页**（如同花顺/东方财富个股页或行情数据接口）核对今日竞价、盘中、收盘与量能，标注 `（来源：个股行情 · 股票名称）`。不得用「不在今日涨停名单」直接推断为断板，必须确认其真实收盘状态。
> - 数据缺失或停牌个股如实标注"不可查/停牌"，不得臆测。

### 第 4 步 · 与今日最新连板梯队对照

将第 2 步建立的**昨日梯队名单**与**今日最新连板梯队**（来自当日 6 页数据中的网页 #6 连板梯队，已在「一、数据来源」读取）逐项交叉比对：

1. **晋级情况**：昨日梯队在今日的成功晋级名单、断板名单、跌停名单。
2. **龙头命运**：昨日总龙头今日是否晋级抬位、高位见顶、断板闷杀或反包。
3. **高度结构变化**：今日最高板高度较昨日是**打开**（空间抬升）还是**压制**（高度下降/断层）。
4. **新老交替**：今日梯队中哪些为昨日既有标的（延续），哪些为新晋标的（新生），判别主线是延续还是切换。
5. **分歧一致验证**：昨日判定"分歧"的个股今日是否转一致，昨日判定"一致"的个股今日是否兑现风险。

### 第 5 步 · 验证并输出结论

将**昨日复盘结论**与今日实盘结果逐项对照，评估**应对状况、准确性、有效性**。昨日结论的来源与兜底规则如下：

- **昨日结论来源**：指上一交易日按本技能（或 `youzi-qijie-jinghua` 体系）产出的四大模块结论（龙头核心 / 情绪周期 / 机会 / 风险），取自上一交易日的复盘输出或历史分析记录。
- **首次运行/无昨日结论**：若当前会话无上一交易日的复盘结论（如首次使用本技能、无历史记录），须在输出中如实标注「无昨日结论记录，仅作梯队数据对照」，**不得凭空编造昨日结论**；此时仅输出昨日梯队→今日实盘的客观数据对照，conclusionCheck 标注为「无昨日结论，跳过验证」。

| 昨日结论 | 今日验证 | 评估 |
|---------|---------|------|
| 判定的（总/分支）龙头 | 今日是否延续强势/晋级/兑现溢价 | 命中 / 偏差 / 失准 |
| 判定的情绪周期阶段 | 今日涨停家数、高度、炸板率是否印证该阶段 | 命中 / 偏差 / 失准 |
| 提示的机会方向 | 相关板块/个股今日是否如期走强 | 兑现 / 未兑现 / 部分兑现 |
| 提示的风险信号 | 今日是否出现对应亏钱效应 | 兑现 / 未兑现 / 部分兑现 |

输出时须给出：**① 命中项**（结论与实盘一致，说明验证充分）；**② 偏差项**（结论与实盘有出入，说明偏差原因，如情绪切换、资金分歧、题材退潮）；**③ 失准项**（结论明显错误，说明误判根源，并总结可改进处）。验证结论须基于第 1–4 步实际数据，不得无据断言。

## 一·补4、大盘与板块因子（今日·昨日）数据提取要点

> 本节为**大盘环境与板块资金合力**的标准化双日数据提取流程：对「大盘因子（今日、昨日）」与「板块因子（今日、昨日）」进行结构化采集，作为研判大盘涨跌幅/量能、板块与概念涨跌幅/主力净额的分析条件。数据由东财网页数据接口提供（今日实时 + 昨日历史），本技能要求分析时**将以下因子全部纳入研判条件**，并逐项标注来源。

### 1. 大盘因子（今日、昨日）

- **今日大盘**：提取上证指数、深证成指、创业板指的最新点位、涨跌幅（%）、涨跌额、成交额（量能）。
  - 来源：`东方财富·大盘指数(今日)`。
- **昨日大盘**：提取上一交易日的三大指数收盘点位、涨跌幅（%）、涨跌额、成交额（量能），用于与今日对比判断放量/缩量、大盘强弱延续或反转。
  - 来源：`东方财富·大盘指数(<昨日日期>)`。

### 2. 板块因子（今日、昨日）

- **今日板块**：分别提取**行业板块**与**概念板块**的：涨跌幅 TOP 与主力净额 TOP（含板块名称、涨跌幅%、主力净流入额、换手率）。
  - 来源：`东方财富·板块涨跌与主力资金(今日)`。
- **昨日板块**：对今日涨幅 TOP / 主力净额 TOP 的板块，提取其在上一交易日的涨跌幅（%）与主力净额（元），用于判断板块是**资金持续流入（主线确立）**、**资金回流（昨日流出今日流入）**还是**资金退潮（连续流出）**。
  - 来源：`东方财富·板块涨跌与主力资金(<昨日日期>)`。

### 3. 研判融入要求（分析条件）

- **大盘环境**：今日大盘涨跌幅 + 量能（与昨日对比）决定整体进攻性——放量上涨=环境转暖、缩量=存量博弈、放量下跌=风险加剧。
- **板块合力**：板块/概念的今日涨跌幅 + 主力净额 + 昨日对照，交叉验证主线题材的资金持续性；净额由负转正且涨幅居前=资金回流信号，连续净流出=退潮信号。
- 上述因子须与「一、数据来源」的 6 个网页数据（涨停/资金流/连板梯队）交叉印证后，再进入「二、分析维度」研判，确保大盘环境与板块合力不是孤立判断。
- 数据缺失（如历史接口不可用）时如实标注该因子缺失，不得编造或顶替。

## 二、分析维度（结合游资交易体系核心数据）

综合 6 个网页数据，从以下维度交叉印证（对应 `youzi-qijie-jinghua` 交易体系的数据需求）：

- **涨停广度与高度**：今日涨停家数、连板家数、最高连板高度 → 判断赚钱/亏钱效应与环境温度。
- **龙头梯队**：连板最高的个股、其所属板块、封单金额、带动板块涨停家数 → 识别总龙头与各分支龙头。
- **情绪周期定位**：结合涨停家数增减、炸板率、高位股表现，界定当前处于**冰点 / 回暖 / 高潮 / 退潮**哪一阶段。
- **资金主线**：大单资金流向 + 概念资金净流入排行 → 找出主力做多主线题材，判别题材新旧。
- **个股资金承接**：个股资金净流入前列 → 验证龙头资金合力，识别分歧/一致的潜在买点，警惕一致后的风险。
- **风险信号**：跌停家数、炸板、资金净流出集中的板块/个股、高位股熄火 → 识别亏钱效应扩散风险。
- **双日对照验证（昨日→今日）**：按「一·补3」流程，将昨日连板梯队个股的今日实盘表现与今日最新连板梯队对照，验证昨日结论的应对状况、准确性及有效性。

## 三、输出格式（固定 5 个模块）

分析完成后，必须**严格按以下 5 个固定模块输出**，每个模块引用所依据的网页数据，逻辑清晰：

### 今日龙头核心
- 今日总龙头及分支龙头（代码/名称/连板/所属板块/封单）。
- 龙头对其他板块的带动性与市场共识强度。
- 依据：涨停板网页 + 个股资金网页数据。

### 今日情绪周期
- 明确判定情绪所处阶段（冰点/回暖/高潮/退潮），并给出判定依据。
- 涨停家数、连板高度、炸板率等关键情绪指标摘要。
- 依据：涨停板网页数据。

### 今日机会
- 资金合力方向、主线题材与潜在机会板块（含概念资金净流入数据支撑）。
- 在龙头确认/分歧转一致前提下的关注方向，标注风险提示。
- 依据：大单资金流向 + 概念资金网页数据。

### 今日风险
- 亏钱效应信号：跌停/炸板/资金净流出集中地、高位股熄火风险。
- 情绪退潮或一致过热的警示，附数据依据。
- 依据：各网页数据交叉得出的风险项。

### 昨日连板梯队 · 今日实盘对照验证
- **昨日梯队复盘摘要**：昨日涨停/连板家数、最高高度、总龙头与分支龙头（来源须标注日期）。
- **今日实盘表现**：昨日梯队个股的晋级/断板/跌停/反包概况，总龙头今日命运。
- **双日对照**：今日最高板高度较昨日打开或压制、新老梯队交替、主线延续或切换。
- **结论验证**：将昨日四大结论（龙头核心/情绪周期/机会/风险）与今日实盘逐项对照，明确标注**命中 / 偏差 / 失准**，偏差与失准项须说明原因。
- 依据：昨日连板梯队 + 今日涨停板/最强个股透视数据。

## 四、输出原则

1. **数据驱动**：每个结论都标注数据来源网页与具体数值，杜绝无据断言。引用数值/图表时严格遵循「一·补2、引用标注规范」的标注格式（如 `（来源：同花顺 连板梯队）`），确保每项数据可验证、可追溯。
2. **逻辑清晰**：结论按「现象 → 数据依据 → 判断」展开。
3. **结论参考价值**：机会与风险模块给出可操作的关注方向，同时明确提示"市场有风险，仅作复盘参考，不构成投资建议"。
4. **诚实标注**：某网页无法访问或数据缺失时，如实说明，不编造行情。
5. **当日在先**：今日研判严格基于限定 6 个网页的**当日**数据，不混入历史或外部信息。历史数据仅限「昨日连板梯队 · 今日实盘对照验证」模块用于双日对照，且必须标注具体日期，不得模糊为"昨日"以免混淆。
