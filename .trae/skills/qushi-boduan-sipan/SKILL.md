# 趋势波段复盘 · 当日行情波段研判

> 本技能基于 **东方财富 + 同花顺** 公开行情数据，对当日 A 股进行「趋势波段」维度的结构化研判。数据来源与采集规范参照「龙头情绪复盘」技能，但分析视角切换为趋势波段：**先判环境与风格 → 再定题材与主线 → 最后选趋势票与买卖点**。输出要求**精炼浓缩但不简略**：每段结论直给判断与依据，不堆砌数据、不写流水账。

## 一·补3、大盘与板块因子（今日·昨日）数据提取要点

> 大盘环境与板块资金合力的标准化双日数据提取流程，作为波段判断的客观环境约束。

### 1. 大盘因子（今日、昨日）
- **今日大盘**：上证指数、深证成指、创业板指的最新点位、涨跌幅（%）、涨跌额、成交额（量能）。来源：`东方财富·大盘指数(今日)`。
- **昨日大盘**：上一交易日的三大指数收盘点位、涨跌幅（%）、涨跌额、成交额（量能），用于对比判断放量/缩量、大盘强弱延续或反转。来源：`东方财富·大盘指数(<昨日日期>)`。

### 2. 板块因子（今日、昨日）
- **今日板块**：行业板块与概念板块的涨跌幅 TOP 与主力净额 TOP（含板块名称、涨跌幅%、主力净流入额、换手率）。来源：`东方财富·板块涨跌与主力资金(今日)`。
- **昨日板块**：对今日涨幅 TOP / 主力净额 TOP 的板块，提取其在上一交易日的涨跌幅（%）与主力净额（元），判断**资金持续流入（主线确立）/ 资金回流 / 资金退潮**。来源：`东方财富·板块涨跌与主力资金(<昨日日期>)`。

### 3. 研判融入要求（分析条件）
- **大盘环境**：今日大盘涨跌幅 + 量能（与昨日对比）决定整体进攻性——放量上涨=环境转暖、缩量=存量博弈、放量下跌=风险加剧。
- **大盘量能评估（个股判断客观约束）**：以两市总成交额今日 vs 昨日计算放量/缩量，作为趋势票判断的客观环境约束——放量环境趋势票有延续空间；缩量环境只做最强趋势票、严控扩散度。该量能口径仅用于内部校准判断，输出文本无需刻意提及量能数字。
- **市场风格**：结合涨停家数、连板高度与炸板率判断当前是**短线连板风格**还是**趋势波段风格**（连板打不高、趋势票持续走强 = 趋势风格），先判风格再选票。
- **板块合力**：板块/概念的今日涨跌幅 + 主力净额 + 昨日对照，交叉验证主线题材的资金持续性。
- 数据缺失（如历史接口不可用）时如实标注该因子缺失，不得编造或顶替。

## 二、分析维度（贴合趋势波段逻辑）

综合各数据源，按趋势波段方法论从以下维度交叉印证（对应 `a股交易方法论` 体系：大局观 → 题材 → 趋势票）：

- **市场风格与波段环境**：短线连板是否退潮、趋势票是否接力；大盘量能放大/萎缩 → 波段环境强/弱。
- **题材方向与运行阶段**：主线题材处于**启动 / 发酵 / 高潮 / 退潮**哪一阶段；题材是否"被消息政策不断刺激"（波段持续的前提）；题材内做地位最高的老大。
- **趋势票筛选**：底部/平台**放量（超过 5 日均量线）→ 缩量调整 → 关键支撑不破**、缩到**量窒息**的票；相对底部、刚启动、左侧无套牢压力的票优先；剔除短线票/ST/有前科的票。
- **量价验证**：放量 → 次日缩量调整（主力锁筹验证成立）即趋势票候选；放量后不缩量 + 资金大幅流出 = 主力没锁筹，剔除。
- **买点信号**：量窒息变盘节点（波段最小量）、突破半路、收红/高开确认起涨三种买点；配合大单净额验证主力入场。
- **仓位纪律**：参照 4321 仓位法——波段票分仓建仓，不满仓、不追已走出主升的票；跌破成本价无条件出局。
- **风险信号**：大盘放量下跌、主线题材资金连续流出、趋势票放量滞涨/爆量大阴线 → 波段风险信号。

## 三、输出格式（三段式，精炼浓缩但不简略）

分析完成后，必须**严格按以下三段式结构输出**，每个结论引用所依据的数据来源，**精炼浓缩**：每段先给判断、再给 1-2 句依据，不堆砌数据、不写流水账：

### 第一段 · 大盘与波段环境
- 大盘强弱（涨跌幅 + 量能放缩）+ 波段环境定性（趋势风格/短线风格、环境强/弱/震荡）。
- 一句结论：当前是否适合做趋势波段，仓位基调如何（参照 4321 仓位法给出基调，不输出数字百分比以外的建议）。

### 第二段 · 主线板块与趋势方向
- 主线题材及运行阶段（启动/发酵/高潮/退潮）、资金持续性判断（持续流入/回流/退潮）。
- 板块内优先关注的方向与代表性标的池方向（不逐一列票，精炼给出方向与梯队关系）。

### 第三段 · 趋势标的池
- 3-5 只趋势票，每只给出：**趋势状态**（放量建仓/缩量整理/量窒息/起涨）、**关键价位**（支撑/压力）、**买点类型**（量窒息埋伏/突破半路/收红确认）、**仓位档位**（仅限四档之一：小/中/大/满）、**一句买卖逻辑**。
- 若候选不足，如实标注「无满足条件趋势票」，不得勉强凑数。

## 四、输出原则

1. **数据驱动**：每个结论都标注数据来源网页与具体数值，杜绝无据断言。
2. **精炼浓缩但不简略**：直接给判断与依据，控制篇幅；宁可每段 3-4 句精炼表达，也不罗列数据流水账。
3. **逻辑清晰**：结论按「判断 → 数据依据 → 操作含义」展开。
4. **波段视角**：始终以趋势波段逻辑分析，不套用短线打板视角；涉及个股分析时，将**集合竞价数据**纳入竞价情绪判断。
5. **诚实标注**：某网页无法访问或数据缺失时，如实说明，不编造行情；"市场有风险，仅作复盘参考，不构成投资建议"。
